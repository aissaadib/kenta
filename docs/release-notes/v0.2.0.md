# Kenta v0.2.0

Music, Appearance Studio, and a faster way to set up clipping.

Kenta keeps a rolling replay buffer of your desktop and saves the last few
seconds when something happens. Clips stay on your PC; Google Drive backup is
optional.

## Downloads

- `Kenta_0.2.0_x64-setup.exe` — per-user Windows installer (no administrator
  rights required).
- `SHA256SUMS.txt` — verify the download before running it.

## What's new

### Music

A local library that references your own files instead of copying them:
FFprobe metadata and embedded artwork, search and sorting, a queue with
reordering, playlists, shuffle and repeat. Playback lives above the navigation,
so music keeps playing while you switch sections, minimise Kenta, or hide it to
the tray.

### Appearance Studio

Themes are semantic tokens applied live through CSS custom properties: seven
built-in presets, a colour editor with WCAG contrast warnings and one-click
fixes, typography, density, corner, sidebar and scale controls, solid, gradient
and image backgrounds, icon packs, custom window and tray icons, per-event
sound cues with imported sounds, undo/redo, and `.kenta-theme` import and
export. Presets are immutable; editing one saves a "(Custom)" copy.

### Clipping settings

- **Two words / One word** tabs choose how you speak a clip: the wake phrase
  followed by the command, or the command on its own. The hint below the tabs
  spells out the exact phrases for the selected mode.
- **Clip sound** accepts any WAV, MP3, OGG, FLAC, M4A, AAC or Opus file. It is
  converted to mono 16-bit WAV and cut to 8 seconds, with a **Test sound**
  button, a volume slider, and one click to go back to a built-in cue.

### Under the hood

Dependency debug symbols are no longer kept in development builds, the unused
`staticlib` artifact is gone, and duplicate FFmpeg sidecars were removed. The
installed application is unchanged in what it can do.

## Requirements

- Windows 10 or Windows 11, 64-bit.
- Microsoft Edge WebView2. It is included with Windows 11 and current Windows
  10; the installer can download the Evergreen Bootstrapper if needed.
- Optional NVIDIA GPU for NVENC. Kenta falls back to CPU x264.
- Optional loopback audio device for desktop sound.

Rust, Node.js, Visual Studio, and a separate FFmpeg install are **not**
required. FFmpeg and FFprobe are included.

## Install

1. Download the installer.
2. Run it. It installs per-user and creates a Start Menu shortcut.
3. Launch **Kenta**.

The installer is **unsigned**, so Windows SmartScreen may show "Windows
protected your PC". Choose **More info → Run anyway** only if the file came
from this repository and its SHA-256 matches `SHA256SUMS.txt`.

```powershell
Get-FileHash .\Kenta_0.2.0_x64-setup.exe -Algorithm SHA256
```

## Upgrade

Install v0.2.0 over v0.1.0. Clips, settings, the clip library, and the Google
Drive credential are stored outside the installation directory and are kept.
The first launch imports any old `settings.json` theme colours into a custom
theme; recordings and clips are untouched.

## Uninstall

Uninstall from **Settings → Apps → Installed apps → Kenta**, or from the Kenta
Start Menu folder. Uninstalling removes the application and shortcuts. It does
not delete recordings, the clip library, settings, or files already in Google
Drive.

## Known limitations

- The installer is unsigned. SmartScreen warnings are expected until a trusted
  code-signing certificate is configured.
- There is no automatic updater yet.
- Capture performance depends on the display, the selected encoder, and the
  hardware. 120 fps is not available on every PC.
- Desktop audio requires a loopback device; some Realtek configurations do not
  expose one.
- Voice recognition depends on the installed Windows speech language.
- The Google Cloud project used by the bundled desktop OAuth client may still
  be in **Testing** mode. In that case only accounts added as test users can
  connect Drive until the consent screen is published.

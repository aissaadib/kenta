# Kenta v0.1.0

First public Windows release.

Kenta keeps a rolling replay buffer of your desktop and saves the last few
seconds when something happens. Clips stay on your PC; Google Drive backup is
optional.

## Downloads

- `Kenta_0.1.0_x64-setup.exe` — per-user Windows installer (no administrator
  rights required).
- `SHA256SUMS.txt` — verify the download before running it.

## Requirements

- Windows 10 or Windows 11, 64-bit.
- Microsoft Edge WebView2. It is included with Windows 11 and current Windows
  10; the installer can download the Evergreen Bootstrapper if needed.
- Optional NVIDIA GPU for NVENC. Kenta falls back to CPU x264.
- Optional loopback audio device for desktop sound.

Rust, Node.js, Visual Studio, and a separate FFmpeg install are **not**
required. FFmpeg and FFprobe are included.

## Install

1. Download the installer.
2. Run it. It installs per-user and creates a Start Menu shortcut.
3. Launch **Kenta**.

The installer is **unsigned**, so Windows SmartScreen may show "Windows
protected your PC". Choose **More info → Run anyway** only if the file came
from this repository and its SHA-256 matches `SHA256SUMS.txt`.

```powershell
Get-FileHash .\Kenta_0.1.0_x64-setup.exe -Algorithm SHA256
```

## Upgrade

Install a newer release over the existing one. Clips, settings, the SQLite
library, and the Google Drive credential are stored outside the installation
directory and are kept.

## Uninstall

Uninstall from **Settings → Apps → Installed apps → Kenta**, or from the Kenta
Start Menu folder. Uninstalling removes the application and shortcuts. It does
not delete recordings, the clip library, settings, or files already in Google
Drive.

## Included

- Rolling replay buffer and manual recording.
- Global save and start/stop hotkeys.
- Clip library with thumbnails, search, sort, preview, rename, and delete.
- Editor with trim, reorder, audio track controls, and export.
- Windows Graphics Capture with a GDI fallback.
- NVENC and CPU x264 encoding through a bundled GPL FFmpeg 9.0 build.
- Microphone and desktop loopback audio.
- Optional Windows SAPI voice clipping.
- Optional Google Drive upload with resumable transfers.

## Known limitations

- The installer is unsigned. SmartScreen warnings are expected until a trusted
  code-signing certificate is configured.
- There is no automatic updater yet.
- Capture performance depends on the display, the selected encoder, and the
  hardware. 120 fps is not available on every PC.
- Desktop audio requires a loopback device; some Realtek configurations do not
  expose one.
- Voice recognition depends on the installed Windows speech language.
- The Google Cloud project used by the bundled desktop OAuth client may still
  be in **Testing** mode. In that case only accounts added as test users can
  connect Drive until the consent screen is published.
